# TRAE 状态页方案 C 设计契约

## 权威来源

- 唯一视觉来源：`docs/prototypes/trae-status-layout.html?variant=C`。
- 单任务权威状态：`tasks=single`。
- 多任务权威状态：`tasks=multiple`。
- 旧 TRAE 页面、A/B/D/E/F/G/H/I/J 原型均不作为实现依据。
- 目标画布：466 × 466，1×，黑色圆形 AMOLED 安全区。

## 页面区域与几何

- 品牌区：TRAE 图标与文字保持现有顶部居中几何，视觉中心约为 `y=45`。
- 状态区：右侧控制台从 `x=161, y=78` 开始，宽 `247`。
  - 第一行只包含 `AGENT` 与 `VOICE` 两个通道。
  - 每个通道由标题、状态圆点和值组成；长 Agent 名称单行尾部省略。
- 统计脊柱：`x=129, y=116, h=246, w=2`。
  - 只保留直线，不显示顶部或底部圆点。
  - Pending 统计锚定在 `x=61, y=274, w=53`。
  - Running 统计锚定在 `x=61, y=322, w=53`。
- 任务区：位于右侧控制台内。
  - 标题显示当前优先状态及其数量。
  - 每条任务只包含项目名、任务名、模型名、Effort。
  - Effort 使用圆角描边标签；模型名保持普通文字。
  - 多任务最多显示当前任务和下一任务；单任务时放大当前任务。
  - 单任务浏览器实测锚点：状态标题 `y=131`、项目名 `y=173`、任务名 `y=201`。
  - 单任务模型/Effort 行不得固定在长标题样例的坐标；它必须跟随任务名的实际渲染高度。短标题显示一行时向上收紧，换成两行时自然下移，间距保持一致。
- 页码点 `y=416`，电池信息 `y=438`，保持现有全局样式和位置。

## 视觉令牌

- 背景：`#000000`。
- 主文字：`#F2F6F8`。
- 次级文字：`#B8C2CC`。
- 弱化文字/分隔线：`#788391`。
- 项目/模型：`#99B1FF`。
- Agent 可用：`#1CE994`。
- Voice 可用/Running：`#49C9EE`。
- Pending：`#FF6248`。
- 错误：沿用 Codex 全局红色状态。
- 英文与数字：Montserrat 系列；中文任务标题使用项目已有 CJK 字体。
- 2026-08-30 第二轮真机反馈再次将 TRAE 页面自有文字整体提升一档：微型文字与 Effort 13 px、模型名 15 px、单任务项目名 17 px、多任务标题 19 px、单任务标题 29 px、统计数字 25 px、品牌字 29 px。公共页码、电池字号和所有既有坐标保持不变。
- 2026-08-30 第三轮真机反馈只调整信息层级：Agent 名称与 Voice 状态值提升到 15 px；任务组标题提升到 14 px；左侧 Pending/Running 汇总标签提升到 14 px，并相对计数向上移动 3 px。其余字号与坐标不变。
- 2026-08-30 第四轮真机反馈：Agent 名称与 Voice 状态值保持 15 px 并改为 Bold；Pending/Running 统计数字从 25 px 提升到 26 px。TRAE Agent 同时兼容旧 `title` 与新版 `generated_title` 日志字段，优先显示真实会话任务名，只有无法获得时才保留 `Trae task` 占位。
- 同轮追加调整：任务名称单独缩小一级，多任务标题 19→18 px、单任务标题 29→28 px；项目名、模型名、Effort、状态文字和既有几何均不变。
- 2026-08-30 第五轮交互修正取代上一条固定字号规则：任务名称始终单行并按实际字形宽度自适应。单任务范围 20–28 px，多任务范围 20–24 px；只有最小 20 px 仍超宽时才尾部省略。每屏最多两条任务，上滑/下滑让两行窗口前进/后退一条，首尾钳制、不循环；取消自动轮换与点击切换，左右页面手势保持不变。
- 拉伸较小字体不等价于目标字号。Latin 多任务标题以完整 Montserrat 24 px 资产为上限、单任务标题以完整 Montserrat 28 px 资产为上限，再按实测字宽向下缩放到最低 20 px；中文标题沿用已验证字库并采用同样的实测宽度比例。其他 Latin 文本继续使用对应的完整字号资产。

## 组件映射

- `TraeStatusPage` 继续拥有全部 LVGL 对象和渲染生命周期。
- Agent/Voice 状态使用同一套全局 Codex 通道判定，不为 TRAE 再造状态机。
- 两条任务行共享同一创建和渲染逻辑，不分别手工设样式。
- Effort 标签由容器和内部标签组成，所有任务共用一致边框、圆角和字号。
- 保留任务优先级；任务区域改由上下滑动控制两行窗口，点击不切换任务，移除自动轮换、机器人图片和动画定时器。

## 状态矩阵

| 状态 | 期望表现 |
| --- | --- |
| 单个 Pending | Pending=1、Running=0；放大单任务；隐藏第二行 |
| 多个 Pending/Running | 显示两个优先任务；统计显示完整计数 |
| 仅 Running | 标题与强调色切换为 Running |
| 无任务 | 隐藏任务行，显示现有空状态文案 |
| Agent 已连接 | 显示已连接 Agent 名称与绿色圆点 |
| Agent 连接中/错误 | 显示全局连接状态文本与对应紫色/红色圆点 |
| Voice Ready/Active | 显示 READY/ACTIVE 与对应绿色/青色圆点 |
| Voice 连接中/错误 | 显示 CONNECTING/ERROR 与对应紫色/红色圆点 |
| 长 Agent/项目/任务/模型 | 单行尾部省略；不得覆盖相邻通道或 Effort 标签 |
| 模型或 Effort 缺失 | 对应字段显示 `--`，布局位置保持稳定 |
| 页面非激活 | 不运行 TRAE 专用动画；再次进入时保留当前仍有效的任务窗口 |

## 验证规则

- 先用依赖无关的布局测试锁定几何、单/多任务规则和触摸区域。
- 运行 TRAE 页面聚焦契约测试，证明机器人资源/定时器已移除且 Effort 标签存在。
- 完成固件构建后，在 466 × 466 的实际 LVGL/真机画面上按品牌区、状态区、统计脊柱、任务区、页脚逐区对照。
- 在获得实际渲染截图前只能报告“实现并编译”，不能报告视觉完成。
- 2026-08-30 第一次真机复核未通过：缺字与数据已修复，但短标题仍沿用两行标题的固定 metadata 坐标，且关键 Latin 字体使用了缩放/偏小字体。该版本不得作为视觉完成证据。
